# `.log_dir` {#.log_dir}

*Package:* `GiottoUtils`  
*Title:* Giotto logging directory

## Description

Set the Giotto logging directory. New logfiles will be generated here.

## Usage

```r
.log_dir(logdir = tempdir())
```

## Arguments

- `logdir`: character. Directory to log to (defaults to tempdir)

## Value

internal setting of option giotto.logdir
