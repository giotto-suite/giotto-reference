# `special_characters` {#special_characters}

*Package:* `GiottoUtils`  
*Title:* Special characters
*Aliases:* `is_latex_output`, `is_utf8_output`, `box_chars`

## Description

Framework and functions for printing with special characters within R
packages.

## Usage

```r
is_latex_output()

is_utf8_output()

box_chars()
```

## Value

boolean

## Details

Much inspiration taken from **fs** [tree.R](https://rdrr.io/cran/fs/src/R/tree.R)
These are derived from: [code](https://github.com/r-lib/cli/blob/e9acc82b0d20fa5c64dd529400b622c0338374ed/R/tree.R#L111)
