# `degrees` {#degrees}

*Package:* `GiottoUtils`  
*Title:* Radian/degree conversions
*Aliases:* `radians`

## Description

Convert radians to degrees and vice versa

## Usage

```r
radians(deg)

degrees(rad)
```

## Arguments

- `deg`: degrees
- `rad`: radians

## Value

numeric

## Examples

```r
radians(180)
degrees(pi)
```
