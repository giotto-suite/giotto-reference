# `.get_img_corners` {#.get_img_corners}

*Package:* `Giotto`  
*Title:* Get image corners

## Description

finds four corner spatial coords of giottoImages or
magick-images

## Usage

```r
.get_img_corners(img_object)
```

## Arguments

- `img_object`: giottoImage or magick-image to use

## Value

data.frame
