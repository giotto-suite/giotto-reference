# `callSpdep` {#callSpdep}

*Package:* `Giotto`  
*Title:* Call the spdep function with required parameters

## Description

Call the spdep function with required parameters

## Usage

```r
callSpdep(method, ...)
```

## Arguments

- `method`: Specify method name to call from spdep with its required
parameters.
- `...`: Additional parameters for the function. See spdep documentation
for relevant parameters.

## Value

Computed statistics from the specified method.
