# `NNClusParam-class` {#NNClusParam-class}

*Package:* `Giotto`  
*Title:* NNClusParam
*Aliases:* `NNClusParam`

## Description

Virtual subclass of `BlusterParam` that designates network clustering
methods which are supported via Giotto-specific methods instead of directly
via **bluster**.
