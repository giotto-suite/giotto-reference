# `.rigid_transform_spatial_locations` {#.rigid_transform_spatial_locations}

*Package:* `Giotto`  
*Title:* Rigid transform spatial locations

## Description

Performs appropriate transforms to align spatial locations
with registered images.

## Usage

```r
.rigid_transform_spatial_locations(spatlocs, transform_values, method)
```

## Arguments

- `spatlocs`: input spatial locations
- `transform_values`: transformation values to use
- `method`: which method is used for image registration

## Value

spatlocs
