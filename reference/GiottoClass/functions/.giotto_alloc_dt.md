# `.giotto_alloc_dt` {#.giotto_alloc_dt}

*Package:* `GiottoClass`  
*Title:* Over-allocation for giotto DT-based info

## Description

Finds DT based objects, overallocates the data.tables, then sets
the objects back in the giotto object

## Usage

```r
.giotto_alloc_dt(gobject)
```

## Arguments

- `gobject`: giotto object

## Value

giotto object
