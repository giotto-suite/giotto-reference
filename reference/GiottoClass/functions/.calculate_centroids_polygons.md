# `.calculate_centroids_polygons` {#.calculate_centroids_polygons}

*Package:* `GiottoClass`  
*Title:* Calculate polygon centroids

## Description

calculates centroids from selected polygons

## Usage

```r
.calculate_centroids_polygons(
  gpolygon,
  name = "centroids",
  append_gpolygon = TRUE
)
```

## Value

SpatVector or giotto polygon
