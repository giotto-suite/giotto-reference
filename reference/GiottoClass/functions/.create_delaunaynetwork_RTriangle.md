# `.create_delaunaynetwork_RTriangle` {#.create_delaunaynetwork_RTriangle}

*Package:* `GiottoClass`  
*Title:* .create_delaunaynetwork_RTriangle

## Description

Create a spatial Delaunay network with RTriangle

## Usage

```r
.create_delaunaynetwork_RTriangle(
  spatial_locations,
  sdimx = "sdimx",
  sdimy = "sdimy",
  Y = TRUE,
  j = TRUE,
  S = 0,
  ...
)
```

## Value

spatial Delaunay network with RTriangle
