# `.check_spatial_location_data` {#.check_spatial_location_data}

*Package:* `GiottoClass`  
*Title:* Check spatial location data

## Description

check cell ID (spatial unit) names between spatial location
and expression data. It will look for identical IDs after sorting.

## Usage

```r
.check_spatial_location_data(gobject)
```

## Value

character or NULL
