# `.py_install_prompt` {#.py_install_prompt}

*Package:* `GiottoClass`  
*Title:* Prompt User for Python Install

## Description

prompts user to install a package

## Usage

```r
.py_install_prompt(package = NULL, env = NULL)
```

## Arguments

- `package`: python package/github url
- `env`: environment into which package will be installed

## Value

numeric
