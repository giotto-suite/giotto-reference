# `showGrids` {#showGrids}

*Package:* `GiottoClass`  
*Title:* Show Spatial Grids

## Description

Show Spatial Grids

## Usage

```r
showGrids(...)
```

## Arguments

- `...`: Arguments passed on to `[showGiottoSpatGrids](=showGiottoSpatGrids)`
  - **`gobject`**: giotto object
- **`nrows`**: number of rows to print

## Value

prints name of available spatial grids

## See Also

`[showGiottoSpatGrids]`
