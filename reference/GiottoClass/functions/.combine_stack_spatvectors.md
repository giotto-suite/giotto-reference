# `.combine_stack_spatvectors` {#.combine_stack_spatvectors}

*Package:* `GiottoClass`  
*Title:* .combine_stack_spatvectors

## Description

combines/aggregates polygons with the same cell ID from
different z-stacks

## Usage

```r
.combine_stack_spatvectors(
  gobject,
  spat_units,
  for_loop = FALSE,
  for_loop_group_size = 100
)
```

## Value

SpatRaster
