# `.plot_giottoimage_mg` {#.plot_giottoimage_mg}

*Package:* `GiottoClass`  
*Title:* .plot_giottoimage_mg

## Description

get and plot a giottoImage either directly or from a giotto
object

## Usage

```r
.plot_giottoimage_mg(gobject = NULL, image_name = NULL, giottoImage = NULL)
```

## Arguments

- `gobject`: giotto object
- `image_name`: name of giotto image `[showGiottoImageNames]`
- `giottoImage`: giottoImage object

## Value

plot
