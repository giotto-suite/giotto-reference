# `init_cell_metadata` {#init_cell_metadata}

*Package:* `GiottoClass`  
*Title:* Initialize cell metadata slot

## Description

Generate cellMetaObjs to hold cell metadata for each spatial
unit

## Usage

```r
init_cell_metadata(gobject, provenance = NULL)
```

## Arguments

- `gobject`: giotto object
- `provenance`: provenance information (optional)
and feature type in the giotto object.

## Value

cellMetaObjs
