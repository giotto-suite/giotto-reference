# `rbind2_giotto_polygon_homo` {#rbind2_giotto_polygon_homo}

*Package:* `GiottoClass`  
*Title:* Append giotto polygons of the same name

## Description

Append two giotto polygons together of the same name.
Performed recursively through `rbind2` and `rbind`

## Usage

```r
rbind2_giotto_polygon_homo(x, y)
```

## Arguments

- `x`: `giottoPolygon` 1
- `y`: `giottoPolygon` 2

## Value

giottoPolygon
