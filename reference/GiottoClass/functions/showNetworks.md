# `showNetworks`

*Package:* `GiottoClass`  
*Title:* Show networks

## Description

Show networks

## Usage

```r
showNetworks(...)
```

## Arguments

- `...`: Arguments passed on to [`showGiottoSpatNetworks`](showGiottoSpatNetworks.md)
  - **`gobject`**: a giotto object
- **`nrows`**: number of rows to print

## Value

prints names and small subset of available spatial network info
