# `headtail` {#headtail}

*Package:* `GiottoClass`  
*Title:* Head and tail
*Aliases:* `head.giottoBinPoints`, `tail.giottoBinPoints`

## Description

Get the head (first values) or tail (last values) of an object

## Usage

```r
head.giottoBinPoints(x, n = 6L, ...)

tail.giottoBinPoints(x, n = 6L, ...)
```

## Arguments

- `x`: object
- `n`: `integerlike` how many to get
- `...`: additional arguments to pass to other methods

## Value

the same class as `x`
